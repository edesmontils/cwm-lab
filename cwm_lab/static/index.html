Aide — boutons et cases

      
    

    

      
Barre d'entête

      
Base URI — l'URI de base du document : les IRI courts (:alice) sont complétés avec elle.

      
Parse — analyse le document « données » et les « règles » (N3/Turtle) ; automatique pendant la saisie, forcé par ce bouton (ou ⌘⏎ / Ctrl⏎). Les erreurs sont localisées ligne/colonne.

      
Exercice + Charger — remplit les éditeurs (données, règles, requête, conclusion) avec l'exercice choisi et affiche son énoncé.

      
Export (N3 / Turtle / NTriples / RDF) — écrit le document courant au format choisi dans l'onglet « Export », avec lien de téléchargement.

      
Langue — change la langue de l'interface (FR/EN) ; le choix est mémorisé localement.

      
Raisonnement

      
Raisonner — applique les règles aux données : la clôture (faits nouveaux) est calculée et affichée dans l'onglet « Raisonnement » ; une incohérence (⊥) est signalée.

      
mode — convergence (think) : les règles s'appliquent jusqu'au point fixe ; 1 passe (applyRules) : chaque règle est appliquée une seule fois.

      
timeout (s) — délai maximum de raisonnement ; 0 = sans limite.

      
règles stockées — copie les énoncés-règles dans la clôture (comme cwm --rules) ; on peut alors les requêter.

      
Interroger

      
Interroger — exécute la requête SPARQL de l'éditeur « Requête » sur la base de connaissances ; les lignes de résultat sont dans l'onglet « Requête ».

      
raisonner avant d'interroger — calcule d'abord la clôture, puis ré-exécute la même requête : les lignes nouvelles (apportées par les règles) sont surlignées.

      
Valider

      
Entraîne ? — vérifie que la conclusion (éditeur « Conclusion ») est bien contenue dans la clôture (données + règles appliquées).

      
Pourquoi ? — génère la preuve de la conclusion dans l'onglet « Preuve » ; on peut ensuite l'altérer à la main.

      
Vérifier la preuve — rejoue la dérivation de la preuve : une preuve valide est acceptée, une preuve altérée est rejetée.

      
Générer (IA)

      
Remplir la base (IA) — génère un jeu de données N3 réaliste (domaine de l'exercice chargé, sinon générique), contrôlé a posteriori (parse, cohérence, plausibilité), et l'injecte dans l'éditeur « données » — à vérifier avant usage.

      
faits ≈ / entités ≈ — taille approximative du jeu de données à générer ; le quota de séance est affiché sous le bouton.

      
Graphe

      
après raisonnement — le graphe calcule d'abord la clôture, puis surligne en orange ce qu'elle ajoute (nœuds et arcs inférés).

      
attributs masqués — masque les nœuds-littéraux : les attributs sont regroupés en pastille (compteur) sur le nœud ; survolez la pastille pour les lire.

      
clic sur un nœud — masque les nœuds qui ne le concernent pas (voisinage direct) ; un clic sur le vide réaffiche tout.
